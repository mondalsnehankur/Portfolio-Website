Campus Learning Management System, running live.

This is my object-oriented Python project, running in your browser. Log in as the administrator, create faculty and student accounts, then enrol, mark attendance, set assignments and grade them. There is no server: everything runs on your device and the data stays in this browser.

How it runs here

                    
The code is the same Python as in the repository. A browser page cannot stop and wait for input() the way a terminal does, so this page makes every function that reaches input() awaitable, in memory only, before running it. Files on GitHub and in this site are unchanged. Data is saved to your browser’s local storage, so other visitors never see your accounts.
