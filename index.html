CURRENTLY WORKING ON

Materials discovery using machine learning.

Ongoing project

An interdisciplinary project applying machine learning to materials science, with the goal of a data-driven system that screens and ranks promising material candidates by their physical, chemical and structural properties.

The first phase builds a structured materials-property database in Python with the mendeleev library: extracting elemental properties, documenting definitions and units, analysing missing data, and investigating allotrope-specific properties so that different forms of the same element are not treated as one.

  1. Built

    Extract

    Atomic, physical and chemical properties pulled with the mendeleev library

  2. Built

    Structure

    Properties organised into reusable CSV datasets

  3. Built

    Validate

    Records checked, missing values found, completeness measured

  4. Built

    Document

    Property dictionary with units and descriptions

  5. Investigating

    Allotropes

    Phase-transition data examined to capture differences between forms of the same element

  6. Planned

    Screen and rank

    Combine elemental and material datasets, then train ML models to rank candidates

PythonMendeleevCSVJSONReportLab

Where it is going: integrating elemental and material datasets, then developing and evaluating ML models that screen and rank candidates for targeted applications. The aim is a practical workflow that supports and speeds up experimental research, not one that replaces experimental validation.
