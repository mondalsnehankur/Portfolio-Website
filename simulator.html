Orbit lab

Launch a spacecraft sideways from a chosen height. At the circular-orbit speed it stays at the same height; slower and it falls into an ellipse (or crashes); at √2 × that speed it escapes. Speeds, periods and energies come from the C functions; a leapfrog integrator written in C advances the orbit.

    How it's built

    1. C source: physics.c, planets.c and space.h are copied unchanged from the Physics-Simulator repository.
    2. Small additions: wasm_api.c exposes those functions to JavaScript and adds the orbit integrator; a tiny maths shim stands in for the C library, which doesn't exist in the browser.
    3. Compiler: clang --target=wasm32 and wasm-ld produce space.wasm (about 4 KB). Rebuild with wasm/build.sh.
    4. Limitation: the shim's pow() only supports whole-number exponents, which is all the original code uses.
